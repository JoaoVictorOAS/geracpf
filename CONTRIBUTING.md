# Contribuindo

Contribuições são bem-vindas! Para propor uma mudança:

1. Faça um fork do repositório.
2. Crie uma branch a partir da `main`: `git checkout -b feat/minha-mudanca`.
3. Instale as dependências: `npm install`.
4. Faça suas alterações e valide o build: `npm run build`.
5. Use mensagens de commit no padrão [Conventional Commits](https://www.conventionalcommits.org/) (`feat:`, `fix:`, `refactor:`, `chore:`...).
6. Abra um Pull Request descrevendo o problema resolvido e como testar a mudança.

## Reportando bugs

Abra uma [issue](../../issues) descrevendo:

* Passos para reproduzir o problema.
* Comportamento esperado x comportamento observado.
* Site/campo onde o autopreenchimento falhou, se aplicável.

## Sugerindo melhorias

Abra uma issue com o rótulo `enhancement` explicando o caso de uso.
